04 / ADD THE ROWS BACK UP

Every correction has an owner.

IPS contributes uᵢrᵢ/n. DR contributes [dᵢ + uᵢ(rᵢ − qᵢ(aᵢ))]/n. SNIPS instead uses normalized weight αᵢ = uᵢ/Σu. The sign of a DR correction can be negative. Removing weight can move DR either way.

07 / LEAVE WITH THE WITNESS
Overlap is an assumption,
not a green light.
Full supplied behavior vectors expose target mass on actions with zero observed-context support. Numeric direct and DR values can still be computed there, but a reward model cannot repair missing nonparametric identification. Positive supplied support does not verify logging probabilities, unseen contexts, hidden confounding, consistency or the sampling process.
ESS = (Σu)²/Σu² describes weight concentration, not validity, statistical coverage or effective independent observations. No estimator ranking, policy selection, safe deployment, new algorithm or causal claim.
